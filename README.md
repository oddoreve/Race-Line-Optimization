# 🏎️ Race Line Optimization

A MATLAB-based **Multi-Objective Racing Line Optimization System** that aims to minimize vehicle lap time and fuel consumption while satisfying track boundary and vehicle performance constraints.

The project implements multiple optimization techniques to analyze the trade-off between racing performance and fuel efficiency, generating optimized racing trajectories, speed profiles, and performance comparisons.

## 📌 Project Overview

In motorsports, finding the optimal racing line is essential for achieving faster lap times while managing fuel consumption.

This project models a vehicle navigating a synthetic closed racing track and optimizes its lateral position to identify different racing strategies.

The system explores four optimization approaches:

- **Weighted-Sum Optimization:** Balances lap time and fuel consumption using different objective weights.
- **Pareto-Front Optimization:** Identifies non-dominated solutions representing trade-offs between speed and fuel efficiency.
- **Fuel Optimization with Lap-Time Constraint:** Minimizes fuel consumption while maintaining a specified lap-time limit.
- **Pure Lap-Time Optimization:** Finds a racing line that minimizes total lap time.

## ⚙️ Methodology

### 1. Track Generation

A synthetic irregular closed racing track is generated using parametric equations.

- Track resolution: 300 points.
- Track width: 10 metres.
- Safety margin: 1.5 metres.
- Track normals are calculated to generate alternative racing trajectories.

### 2. Vehicle Modeling

The vehicle model incorporates the following parameters:

| Parameter | Value |
|---|---:|
| Vehicle mass | 800 kg |
| Friction coefficient | 1.4 |
| Maximum engine power | 250 kW |
| Maximum speed | 80 m/s |
| Drivetrain efficiency | 90% |
| Engine efficiency | 30% |
| Air density | 1.225 kg/m³ |
| Drag coefficient | 0.9 |
| Frontal area | 1.5 m² |

These parameters are used to estimate vehicle performance under different racing conditions.

### 3. Racing Line Generation

The racing line is generated by applying lateral offsets to the track centreline.

Periodic piecewise cubic interpolation (`pchip`) is used to construct smooth racing trajectories.

The optimization algorithm adjusts 24 lateral control points to find suitable racing lines while respecting track constraints.

### 4. Speed Profile Calculation

The vehicle speed profile is determined using:

- Maximum cornering speed.
- Lateral acceleration limits.
- Engine power limitations.
- Longitudinal acceleration limits.
- Braking constraints.

Forward acceleration and backward braking passes are repeatedly applied to obtain a feasible speed profile.

### 5. Objective Function

The optimization considers two primary objectives:

**Lap Time Minimization**

Minimize the total time required to complete one lap.

**Fuel Consumption Minimization**

Minimize total fuel consumption based on engine power demand, drivetrain efficiency, engine efficiency, and idle fuel consumption.

The combined normalized weighted objective is:

\[
J = w_T\frac{T}{T_{ref}}+
w_F\frac{F}{F_{ref}}
\]

Where:

- \(T\) = Lap time
- \(F\) = Fuel consumption
- \(w_T\) = Lap-time weight
- \(w_F\) = Fuel-consumption weight
- \(T_{ref}\) and \(F_{ref}\) = Baseline reference values

## 🧠 Optimization Techniques

### Method 1: Weighted-Sum Optimization

Uses MATLAB's `fmincon` optimizer with the SQP algorithm.

Five different weight combinations are evaluated:

| Lap Time Weight | Fuel Weight |
|---:|---:|
| 0.9 | 0.1 |
| 0.7 | 0.3 |
| 0.5 | 0.5 |
| 0.3 | 0.7 |
| 0.1 | 0.9 |

This demonstrates how changing optimization priorities affects racing performance.

### Method 2: Pareto-Front Optimization

Uses MATLAB's `gamultiobj` genetic algorithm to identify Pareto-optimal solutions.

Three representative solutions are extracted:

- Pareto Fastest
- Pareto Minimum Fuel
- Pareto Balanced

### Method 3: Minimum Fuel with Lap-Time Constraint

Minimizes fuel consumption while restricting lap time to a maximum of 5% above the fastest Pareto solution.

### Method 4: Pure Minimum Lap Time

Uses `fmincon` to minimize lap time without explicitly optimizing fuel consumption.

The project generates a comparison of different optimization strategies.

The following results are from the included `methodComparison.csv`:

| Optimization Strategy | Lap Time (s) | Fuel (kg) |
|---|---:|---:|
| Weighted Sum (0.9/0.1) | 13.968 | 0.12054 |

| Weighted Sum (0.3/0.7) | 14.506 | 0.12003 |
| Weighted Sum (0.1/0.9) | 15.021 | 0.11521 |
| Pareto Fastest | 14.171 | 0.12588 |
| Pareto Minimum Fuel | 14.531 | 0.12141 |

| Minimum Fuel with Time Limit | 14.636 | 0.11895 |
| Pure Minimum Lap Time | 13.799 | 0.12669 |

**Key observations:**

- Pure minimum lap-time optimization achieves the lowest reported lap time of approximately 13.799 seconds.
- Weighted-sum optimization provides different performance and fuel-consumption trade-offs.
- Pareto optimization identifies multiple non-dominated racing strategies.
- Fuel-constrained optimization reduces fuel consumption while imposing a lap-time restriction.

*Note: These are the results stored in the provided CSV file, not independently reproduced benchmark measurements.*

You need:

Clone the repository:
